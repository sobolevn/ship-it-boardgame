# What is this?

This is a folder for the English translation of this game.
The Russian version in [`ru/`](../ru) is the source of truth:
if the two ever disagree, the Russian version wins.

## Contents

- [Rules](rules.md)
- [FAQ](faq.md)
- [Card reference](cards.md): English text of every card, since the printable cards are still in Russian
- [House rules](homebrew.md)
- `schemas/`: diagrams used in the rules, `schema-sources/`: their `draw.io` sources
